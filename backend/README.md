# Backend

Публичный API сохранен прежним, но исходная логика MVP разделена на слои и убраны несколько проблем с надежностью обработки файлов.

## Архитектура

- `config.py` читает переменные окружения и собирает инфраструктурные URL.
- `database.py` отвечает за async SQLAlchemy engine, session factory и FastAPI-зависимость сессии.
- `storage.py` потоково сохраняет загруженные файлы и изолирует работу с путями.
- `repositories.py` содержит запросы к базе данных.
- `processing.py` содержит чистую логику сканирования, извлечения метаданных и сборки алертов.
- `service.py` координирует транзакции и бизнес-сценарии.
- `tasks.py` запускает фоновую обработку файла в Celery.

## Что изменено

- Сохранен прежний набор endpoints: `/files`, `/alerts`, download, update, delete.
- Конфигурация БД и Celery вынесена из бизнес-логики.
- Upload сохраняет файл потоково, без чтения всего содержимого в память.
- Название файла валидируется до записи файла на диск.
- Если запись в БД падает после сохранения файла, файл удаляется из storage.
- Удаление файла сначала удаляет связанные alerts, затем запись файла и сам файл.
- Alembic больше не импортирует `service.py` с побочными эффектами, а берет DB URL из `config.py`.
- Добавлены индексы на поля, по которым идут сортировки и связь alerts с файлами.

## Оптимизация

Старая цепочка из трех Celery-задач заменена на одну фоновую задачу на файл.

Было:

```text
scan_file_for_threats -> extract_file_metadata -> send_file_alert
```

Стало:

```text
process_uploaded_file_task
  -> scan
  -> extract metadata
  -> create alert
```

Сканирование, извлечение метаданных и создание алерта остались отдельными функциями, но worker больше не отправляет два лишних сообщения в Redis и не загружает одну и ту же запись в трех независимых задачах.

## Запуск и проверка

```bash
docker compose -f docker-compose.dev.yml up -d backend-db backend-redis backend backend-worker
docker exec backend alembic upgrade head
```

Backend доступен по адресу:

```text
http://127.0.0.1:8000/docs
```

Локальные unit-тесты чистой логики:

```bash
python -m unittest discover -s tests
```
